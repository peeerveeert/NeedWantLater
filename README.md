# NeedWantLater

Мобильная PWA-напоминалка для будущих трат, потребностей и хотелок. Это не бюджетник и не todo-list: приложение хранит всё, что «занимает место в голове», и раскладывает по NEED / WANT / LATER.

## Что уже работает

- быстрый ввод обычным человеческим языком;
- автоматическое определение NEED / WANT / LATER;
- автоматическая категория и тематическая иконка;
- распознавание известной/примерной цены и диапазонов (`30к`, `20–40к` и т.п.);
- автоматический «следующий шаг»;
- возможность поправить решение приложения перед сохранением;
- визуальная доска с мягкими органическими карточками и градиентами;
- максимум 2 карточки в ряд на телефоне — без слишком мелких tap-target'ов;
- нижняя навигация из 4 равных зон: Обзор / Поиск / + / Закрыто;
- поиск;
- закрытие и возврат элементов;
- редактирование и удаление;
- локальное хранение на устройстве;
- PWA / установка на домашний экран;
- офлайн-кэш после первого открытия.

## Визуалы

В MVP приложение автоматически подбирает тематическую иконку и цветовую подачу. Архитектура оставлена простой, чтобы следующим шагом можно было подключить автоматический подбор реального изображения предмета/образа через отдельный image endpoint, не переделывая карточки.

## Запуск

Нужен любой статический HTTP-сервер. Например:

```bash
python3 -m http.server 8080
```

После этого открыть `http://localhost:8080`.

Для установки PWA на iPhone production-развёртывание должно работать по HTTPS.

## Проверки

```bash
node --check app.js
node --check classifier.js
node tests.mjs
```

## Файлы

- `index.html` — интерфейс и экраны;
- `styles.css` — дизайн, responsive/mobile UX;
- `classifier.js` — локальная автоклассификация;
- `app.js` — состояние, формы, навигация и localStorage;
- `manifest.webmanifest` — PWA manifest;
- `sw.js` — offline cache;
- `tests.mjs` — smoke-проверки классификатора.

## Почему пока без аккаунта и сервера

Первый релиз намеренно не требует регистрации, API-ключа, банка или облачной базы. Он работает мгновенно и хранит личные хотелки только на устройстве. Позже можно добавить синхронизацию и AI/image endpoint отдельным слоем.
